# Estudos ISO · Auditoria

Série de estudos autoinstrucionais sobre a ISO 9001 e as ferramentas da qualidade. Cada estudo tem um treinamento para ler, em HTML, e uma planilha para usar, em XLSX.

Para começar, abra o arquivo `index.html` no navegador.

## Avisos

- Os exemplos, os documentos e os números são ilustrativos e foram criados para fins didáticos.
- As referências às normas ISO são resumos, escritos com palavras próprias. Elas não substituem o texto das normas. Confira a edição vigente antes de citar um requisito em relatório.
- As escalas, as pontuações e as faixas usadas nas planilhas são convenções deste material.
